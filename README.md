# 🛒 Full Stack E-Commerce

A modern Full Stack E-Commerce web application developed with Angular, Node.js, Express.js and MySQL.

## 🚀 Project Overview

This project is designed to demonstrate Full Stack Web Development skills, including frontend development, backend API development and database management.

## 🧰 Technologies

### Frontend
- Angular
- TypeScript
- HTML5
- CSS3

### Backend
- Node.js
- Express.js
- REST API

### Database
- MySQL

### Tools
- Git
- GitHub
- VS Code

## ✨ Features

- 🔐 User authentication
- 🛍️ Product catalog
- 🛒 Shopping cart
- 📦 Order management
- 👤 User management
- 🔎 Product search
- 📊 Admin dashboard
- 🔌 REST API
